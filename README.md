# 全家人出國旅遊規劃工作台

北海道、首爾、德國與義大利已放入待規劃清單。東京與大阪在「已完成旅程」。方案名稱和活動是可編輯的草案，出發日期、旅費與訂位資訊由家人確認後填寫。封面使用生成的旅遊情境圖。

## 開始規劃

1. **待規劃方案**。按「新增方案」或卡片上的鉛筆，輸入日期、全家預算上限與活動類型。同一目的地可以建立多個方案。總覽可同時依目的地、日期、預算、活動類型和準備狀態篩選。日期區間採重疊比對。預算篩選優先採用上限，上限空白時採用預算項目合計。
2. **比較與評分**。在「方案比較」勾選候選，再依預算、日期、家人喜好及交通各給 1 至 5 分。預設權重依序為 30、25、30、15，可自行調整。每項有權重的評分填完後，工作台會依「各項分數乘權重後加總 ÷（5 × 權重總和）× 100」計算，四捨五入到小數第 1 位。可依總分排序。
3. **行程草案**。以第幾天和當地時間排活動，填寫地點、類型及來源。可用箭頭調整同日順序。切換成按時間顯示後，可把結果儲存為自訂順序。行程日期依方案的出發日加上天數換算。
4. **航班與住宿**。新增候選，填寫全家總價、來源網址與查證日期。可改成優先考慮或已預訂，核對後再勾選已確認。報價由使用者填入。
5. **待辦與文件**。可指定給方案或設成全家共用。記下負責人、截止日、文件有效期限與存放位置。護照號碼、掃描檔及訂位代碼請另存於家人信任的私人空間。
6. **家庭偏好與費用分攤**。編輯成員稱呼、興趣、飲食及行動需求後，就能指定待辦負責人與費用分攤成員。所有金額以新臺幣整元輸入。已確認的每筆支出會由選定的成員均分。若有餘數，依該筆分攤名單次序每人多分 1 元，直到分完。分攤結果會列出應收、應付與建議轉付。
7. **完成旅行**。在方案頁按「標記已完成」即可歸檔。歸檔後仍可回看或編輯行程及支出，也可移回規劃。

## 備份與還原

- 修改儲存在目前的瀏覽器。同一個網站在同一瀏覽器開啟的分頁會讀取更新。換裝置、瀏覽器或網址時，可用匯出的 JSON 轉移資料。
- 按「匯出備份」下載工作台資料。備份包含家人自行填入的內容，請另存於你選擇的位置。
- 在「資料與使用說明」選擇「匯入 JSON」。畫面會檢查格式及方案與成員的連結，再顯示資料筆數。確認後會整份替換目前瀏覽器的資料。
- [空白範本](./data/template.json)可用來整理資料。[JSON Schema](./data/schema.json)列出資料的欄位與選項。手動編輯可參考現有的匯出檔，保留識別碼和各紀錄的連結。

| JSON 欄位 | 內容 |
| --- | --- |
| `schemaVersion` | 資料版本，填 `1`。 |
| `weights` | `budget`、`dates`、`family`、`travel` 的權重。 |
| `trips` | 目的地、方案名稱、日期、預算、活動、狀態與評分。 |
| `members` | 家庭成員的稱呼與偏好。 |
| `itinerary` | 方案內活動的天次、當地時間與排序。 |
| `flights`、`stays` | 各方案的航班與住宿候選。 |
| `budgetItems`、`expenses` | 估算項目與實際支出。 |
| `tasks`、`documents` | 待辦與文件索引。 |

`tripId` 連到 `trips[].id`。待辦和文件可用空字串表示全家共用。`memberId`、`paidBy` 和 `shareWith` 的值連到 `members[].id`。每個陣列內的 `id` 須唯一。日期採 `YYYY-MM-DD`，活動時間採 `HH:mm`，航班當地日期時間採 `YYYY-MM-DDTHH:mm`。未知日期保留空字串，選填金額及未評分項目用 `null`。用 `confirmed` 記錄資料已核對。

## 部署到 GitHub Pages

1. 解壓縮，把檔案放到 GitHub 儲存庫根目錄，包含 `.nojekyll`。網站入口是 `index.html`。
2. 將檔案推到 `main` 分支。在儲存庫的 **Settings → Pages**，於 **Build and deployment** 選擇 **Deploy from a branch**。
3. 選 **main** 及 **/(root)** 後按 **Save**。部署完成後從 Pages 設定頁開啟網站。若檔案放在其他分支，請選該分支。
4. 所有素材與程式都在部署包內，網站使用相對路徑，可放在 GitHub Pages 的專案子路徑。從 Sites 轉移到 GitHub Pages 時，可用 JSON 備份搬移已填資料。

[GitHub Pages 官方部署說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

在電腦預覽時，可於解壓縮的資料夾執行 `python3 -m http.server 8000`，再開啟 [http://localhost:8000](http://localhost:8000)。
